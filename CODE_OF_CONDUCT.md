# Code of Conduct

Ghost Developer Studio is a one-person studio, and this project is
maintained in the open. The rules are short:

- Be decent to each other. Critique code and ideas as hard as you
  like; don't make it personal.
- No harassment, slurs, or targeted nastiness — in issues, PRs, or
  anywhere the project shows up.
- Assume good faith first. Most "bad" contributions are honest
  mistakes; most disagreements here are about trade-offs, not people.
- Maintainers may remove comments, close threads, or block accounts
  that break these rules, without a debate about it.

Reports: gdev6145@gmail.com. They'll be read by the maintainer and
kept as private as the situation allows.

This is a plain-language covenant, written for a small project —
modeled in spirit on the Contributor Covenant, without the legal
machinery.
